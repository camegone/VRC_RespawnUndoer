# 概要
リスポーンするときに位置を記録し、その地点にテレポートして戻ることを可能とするギミックです。リスポーン地点付近から動かずにリスポーンボタンを再度押すことで元の地点に戻れます。\
This is a gimmick that store the position on respawning, and let you to be recalled on the location. You can return to your original location by pressing the respawn button again without moving from the respawn point.\
リスポーン地点にあるペンなどのオブジェクトを掴んで戻ってきたり、joinしてきた人の様子を見てから戻るなどの用途があります。\
This can be used to grab an object such as a pen at the respawn point and return, or to see of someone who has joined and return.\
外部のテレポーター系ギミックと連携して元の地点に戻れるギミックとしても利用できます。\
It can also be used in conjunction with an external teleporter gimmick to return to your original location.

## 設定; setteings
- Allow Double Click Respawn
プレイヤーがリスポーンエリアでリスポーンすることで元の地点にテレポートすることを許可するかどうか。\
Whether allow players to undo respawn by respawning in respawn-area.
- Objects To Be Moved On Respawn
リスポーン時に元いた地点に移動されるオブジェクトを設定する。\
Sets the object that will be moved to the original location upon respawn.
- Box Collider
リスポーンエリアの大きさを設定する。このエリア内では位置は記録されない。\
Sets the size of the respawn area. Positions are not recorded within this area.
